# Sudoku Solver

A simple browser-based Sudoku puzzle helper built with HTML, CSS, and JavaScript.

## Purpose

This project lets users:
- enter a Sudoku puzzle
- validate the board
- get a hint
- clear the board
- load a sample puzzle
- solve the puzzle using backtracking


## Run locally

Open `index.html` in a browser.

## Notes

This is a lightweight front-end learning project and does not require a backend or database.
